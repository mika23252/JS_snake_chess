# JS Snake & Chess

Небольшой браузерный проект на чистых HTML, CSS и JavaScript. Главная страница объединяет две игры: «Змейку» и шахматы.

## Возможности

### Главная страница

Файл `main.html` содержит стартовое меню с переходами к играм. Кнопка в шапке меняет оформление градиента.

### Змейка

Игра реализована в `snake.html` и `snake.js`.

- Игровое поле по умолчанию — 21 × 21 клетка.
- Управление: стрелки клавиатуры, WASD или клавиши цифрового блока 8 / 4 / 2 / 6.
- Для победы нужно набрать 15 очков, собирая еду.
- При выходе за границу поля змейка появляется с противоположной стороны.
- Столкновение змейки с собственным телом завершает игру.
- Кнопки интерфейса позволяют начать или остановить игру и начать новую.

### Шахматы

Шахматная игра находится в каталоге `chess/`:

- `board.html` — страница игрового поля;
- `board.css` — стили доски и элементов интерфейса;
- `script.js` — логика игры.

Интерфейс отображает историю ходов, съеденные фигуры и отдельные таймеры для белых и чёрных. Кнопка «Заново» сбрасывает партию.

## Запуск

Сборка и установка зависимостей через npm не требуются.

1. Скачайте репозиторий или клонируйте его.
2. Откройте файл `main.html` в современном браузере.
3. Нажмите «Играть» и выберите нужную игру.

Также можно запустить простой локальный HTTP-сервер из корневой папки проекта:

```bash
python -m http.server 8000
```

После этого откройте в браузере адрес `http://localhost:8000/main.html`.

## Зависимости

Локальные файлы проекта не требуют сторонних JavaScript-библиотек. Главная и шахматная страницы подключают Open Sans и Font Awesome через внешние CDN-сервисы. Для загрузки этих шрифтов и иконок требуется подключение к интернету; без него оформление может отличаться, но основная логика игр остаётся в локальных файлах.
